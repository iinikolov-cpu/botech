# Запуск бота для новичков

Идея простая: арендуем маленький сервер (компьютер в интернете), копируем на него бота и запускаем.
Так вам ничего не нужно устанавливать на свой компьютер, а бот работает круглосуточно.

Все команды ниже вводятся **в окне терминала, подключённого к серверу** (шаг 3). Не в Telegram и не в этом чате.

## Шаг 1. Создайте бота в Telegram (5 минут)

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите «Запустить».
2. Отправьте `/newbot`.
3. Введите название бота (любое, например «Тайный покупатель»).
4. Введите username: латиница, обязательно заканчивается на `bot` (например `mystery_shopper_uz_bot`).
5. BotFather пришлёт **токен**: длинная строка вида `123456789:AAH...`. Скопируйте и сохраните в заметки. Это пароль от бота, никому его не показывайте.
6. Узнайте свой Telegram ID: найдите **@userinfobot**, нажмите «Запустить». Он пришлёт число (`Id: 123456789`). Сохраните его.

## Шаг 2. Арендуйте сервер (10 минут)

Подойдёт любой хостинг, где можно взять сервер с **Ubuntu 24.04**. Рекомендую Hetzner (около 4 EUR в месяц).

1. Зайдите на https://www.hetzner.com/cloud и зарегистрируйтесь (нужна банковская карта и подтверждение личности).
2. Создайте проект: кнопка **New project**, любое имя.
3. Внутри проекта нажмите **Add Server** и выберите:
   - **Location**: любая европейская (Falkenstein, Nuremberg или Helsinki);
   - **Image**: **Ubuntu 24.04**;
   - **Type**: **Shared vCPU**, самый дешёвый тариф;
   - **Networking**: оставьте по умолчанию;
   - **SSH keys**: ничего не добавляйте, тогда пароль пришлют на почту;
   - остальное не трогайте.
4. Нажмите **Create & Buy now**.
5. Через минуту сервер появится в списке. Запишите его **IP-адрес** (например `95.216.1.2`). Пароль root придёт на вашу почту.

## Шаг 3. Подключитесь к серверу

**Windows 10/11:** нажмите кнопку Пуск, наберите `PowerShell`, откройте.
**Mac:** откройте программу «Терминал».

В открывшемся окне введите (замените IP на свой) и нажмите Enter:

```
ssh root@95.216.1.2
```

- На вопрос `Are you sure you want to continue connecting?` ответьте `yes`.
- Введите пароль из письма. **Символы пароля при вводе не отображаются**, это нормально. Лучше вставить пароль правой кнопкой мыши.
- Сервер сразу попросит придумать новый пароль: введите старый, затем дважды новый.
- Когда увидите приглашение вида `root@ubuntu-...:~#`, вы на сервере. Дальше все команды вводятся здесь.

Если ssh не работает: на странице сервера в Hetzner есть кнопка консоли (значок `>_` справа вверху), это тот же терминал прямо в браузере.

Вставка в терминал: правая кнопка мыши (Windows) или Cmd+V (Mac).

## Шаг 4. Установите Docker (2 минуты)

Введите по одной команде:

```
apt-get update && apt-get install -y git
curl -fsSL https://get.docker.com | sh
```

Дождитесь окончания (побегут строки текста). Проверка:

```
docker --version
```

Должна показаться версия Docker.

## Шаг 5. Скачайте бота

```
git clone -b claude/telegram-secret-shopper-bot-v9tvy7 https://github.com/iinikolov-cpu/botech.git
cd botech
```

Если git просит логин и пароль, значит репозиторий закрытый. Самый простой выход: на GitHub откройте репозиторий, Settings, внизу Danger Zone, Change visibility, Public. В коде нет паролей и токенов (они хранятся только на сервере), поэтому это безопасно. Потом повторите команду.

## Шаг 6. Впишите настройки

```
cp .env.example .env
nano .env
```

Откроется простой текстовый редактор. Стрелками переместитесь и допишите значения после `=` (без пробелов и кавычек):

```
BOT_TOKEN=123456789:AAH...ваш токен
FIRST_ADMIN_ID=123456789   <- ваш Telegram ID из шага 1
```

Остальные строки не трогайте. Сохранить: **Ctrl+O**, затем **Enter**. Выйти: **Ctrl+X**.

## Шаг 7. Запустите

```
docker compose up -d --build
```

Первый раз это займёт 2-4 минуты (идёт сборка). В конце должно быть `Started`.

Посмотрите, что бот жив:

```
docker compose logs
```

Ищите строку `"msg":"бот запущен"`. Если вместо неё ошибка, смотрите раздел «Если что-то не так».

## Шаг 8. Проверьте в Telegram

1. Откройте своего бота (ссылка из BotFather) и нажмите «Запустить». Так как вы первый админ, бот ответит приветствием.
2. Отправьте `/admin`: должна появиться панель с кнопками.
3. Нажмите **Инвайты**, затем **На 1 чел.**: бот покажет ссылку-приглашение.
4. Отправьте ссылку с другого аккаунта Telegram (друг, второй телефон) и нажмите «Запустить». Тот аккаунт увидит «Заявка отправлена».
5. Вам придёт сообщение «Новая заявка» с кнопками. Нажмите **Одобрить**.
6. Второй аккаунт получит «Заявка одобрена».
7. Проверка закрытого доступа: с третьего аккаунта напишите боту что угодно. Ответ должен быть только «Нет доступа».

## Полезные команды (всегда из папки `botech`)

| Что сделать | Команда |
|---|---|
| Посмотреть логи вживую (выход Ctrl+C) | `docker compose logs -f` |
| Перезапустить | `docker compose restart` |
| Остановить | `docker compose down` |
| Обновить до новой версии | `git pull && docker compose up -d --build` |

Если вы закрыли терминал и зашли заново: `ssh root@ВАШ_IP`, затем `cd botech`.

База данных хранится в отдельном томе Docker и не пропадает при обновлениях.

## Если что-то не так

- **Бот молчит.** Выполните `docker compose logs` и посмотрите последние строки.
- **`не задана переменная BOT_TOKEN` или `FIRST_ADMIN_ID должна быть числом`.** Вы не сохранили `.env` или ошиблись. Откройте `nano .env` и проверьте: без пробелов и кавычек.
- **`Unauthorized` в логах.** Токен скопирован неверно. Возьмите новый у BotFather (`/mybots`, выбрать бота, API Token).
- **`команда не найдена: docker`.** Шаг 4 не завершился, повторите его.
- **После `/admin` тишина.** Ваш ID в `FIRST_ADMIN_ID` не совпадает с реальным. Проверьте у @userinfobot, поправьте `.env` и выполните `docker compose up -d`.
